Controlos
Mouse  → passe sobre a imagem para revelar / clique para explosão
R      → resetar revelação (restaura a camada original)
B      → splash de sangue na posição atual do cursor
Slider → ajusta a intensidade (tamanho das gotas e raio de erosão)
